# Security Policy

## Supported versions

Security fixes are provided for the latest released version. Users should
upgrade before reporting an issue that is already fixed in a newer release.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's **Report a vulnerability** function in
the Security tab of the affected EnvPlane repository. Include affected
versions, impact, reproduction steps, and any suggested mitigation.

We aim to acknowledge complete reports within three business days. Please do
not disclose the issue publicly until a fix or coordinated disclosure date has
been agreed.

Never include production credentials, customer data, or active exploit payloads
in a report. Use synthetic examples and redact sensitive values.
